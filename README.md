# E-commerce Sales & Ad Spend Dashboard

A complete data analytics project that turns messy e-commerce transaction data into a professional, interactive business dashboard. Built for freelancers and analysts who need to deliver **client-ready insights fast**.

## 🚀 What It Does

This project cleans 12,000+ rows of raw transaction data, merges advertising spend, calculates key metrics (Revenue, ROAS, Profit after Ads), and exports a **fully interactive Excel dashboard** with dark-theme styling, PivotTables, and dynamic Slicers.

### 🔧 Two Delivery Formats

1. **Excel Dashboard (Client Deliverable)**  
   - `Sales_Dashboard_Polished.xlsx` – a fully formatted workbook with:
     - **5 PivotCharts**: Revenue by Category & Status, Revenue by Country, Revenue by Payment Method, Monthly Revenue Trend, ROAS by Category.
     - **5 Slicers**: Filter by Product Category, Country, Payment Method, and Revenue Type (Fulfilled vs. Cancelled).
     - **Dark Theme**: Professional black background with white text, optimized for client presentations.
   - *Just open the file and start filtering – no setup required.*

2. **Streamlit Web App (Hosted Interactive Version)**  
   - Run `streamlit run app.py` locally to get the same insights in a web interface with sidebar filters.

### 📊 Key Metrics Calculated

- **Total Revenue** ($1.40M)
- **Fulfilled Revenue** ($1.15M) vs **Cancelled/Returned Revenue** ($253K)
- **Total Ad Spend** ($375K)
- **ROAS (Return on Ad Spend)** – 2.94x overall, broken down by category
- **Profit After Ads** ($760K)
